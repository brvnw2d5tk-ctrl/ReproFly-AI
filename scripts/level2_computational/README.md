# Level-2 reconstruction (supplementary)

The public, supported workflow is the offline paper-level reproduction in the
package root README. The scripts in this directory are supplementary wrappers;
they do not currently provide an end-to-end, independently runnable rebuild
from raw source data.

Source-data release identifiers and checksums have not been finalized.
Member-level ground-truth mappings and their supporting evidence are controlled
and are not included. Therefore this package does not let a reader independently
reconstruct or verify the sealed target identities. No Level-2 completion claim
is made here.

The wrappers and dataset inventory are retained as implementation notes. Do
not treat their status output as evidence that raw-data reconstruction or
trajectory re-scoring has run.
